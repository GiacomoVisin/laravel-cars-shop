# 🚗 Gestionale Officina Meccanica

Applicazione web Full-Stack progettata per la gestione digitale dell'inventario veicoli di un'officina meccanica. Il sistema permette di visualizzare la lista completa delle auto in gestione, registrare nuovi veicoli, aggiornarne i dettagli ed eliminarli in tempo reale tramite chiamate API asincrone.

---

## ✨ Funzionalità Principali

* **📋 Visualizzazione Inventario (Index):** Elenco completo e dinamico di tutte le vetture presenti in officina.
* **➕ Inserimento Veicoli (Create):** Form intuitivo per registrare nuove automobili nel database con validazione dei dati.
* **✏️ Modifica Dati (Update):** Aggiornamento rapido delle informazioni di ciascun veicolo (es. targa, modello, stato riparazione, ecc.).
* **🗑️ Rimozione Veicoli (Delete):** Eliminazione delle vetture completate o non più in carico con aggiornamento immediato dell'interfaccia.
* **📱 Interfaccia Responsive:** Layout adattabile a desktop, tablet e smartphone realizzato con Bootstrap e CSS custom.
